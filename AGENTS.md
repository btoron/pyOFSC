# Instructions for coding agents

Before creating or submitting a pull request, read `CONTRIBUTING.md` and follow its contribution requirements.

In particular:

- Every commit must have a cryptographic signature (GPG, SSH, or S/MIME) that GitHub verifies as **Verified**. A `Signed-off-by` line is not a cryptographic signature and does not meet this requirement.
- Keep feature branch history linear; do not include merge commits. Rebase when needed to preserve a clean, reviewable history.
- After pushing, verify on GitHub that every commit displays the **Verified** badge.

See the commit-signing setup guide linked from `CONTRIBUTING.md`: https://docs.github.com/en/authentication/managing-commit-signature-verification/signing-commits
